# Gianni Bussoletti • Personal Portfolio

> Portfolio personale in stile Windows 9️⃣5️⃣
> con una selezione di progetti front-end e back-end, sezione "Su di me"
> e contatti diretti. Disponibile in italiano e inglese.

---

## 🖥 Stack tecnologico

```
┌────────────────────────┬──────────────────────────────────────────────┐
│ Ambito                 │ Tecnologia                                   │
├────────────────────────┼──────────────────────────────────────────────┤
│ Framework              │ React 19, TypeScript                         │
│ Build tool             │ Vite                                         │
│ UI                     │ React Bootstrap, Bootstrap 5, Sass           │
│ Icone                  │ FontAwesome                                  │
│ Internazionalizzazione │ i18next, react-i18next,                      │

└────────────────────────┴──────────────────────────────────────────────┘
```

## 🌐 Traduzioni

I testi sono gestiti tramite `react-i18next`, con i file di traduzione
organizzati per lingua. Il cambio lingua è disponibile tramite l'apposito
selettore nell'interfaccia.
